Accessibility

Effective November 20, 2026

I want everyone to be able to use this website, including people with disabilities.

What I've Done

  • Designed the site with the Web Content Accessibility Guidelines (WCAG) 2.0 Level AA in mind, including colour contrast, text alternatives for images and clear headings.
  • Made the site usable with a keyboard, with visible focus outlines and a "Skip to content" link.
  • Labelled form fields and buttons so screen readers can announce them.
  • Respected your device's "reduce motion" setting by turning off animations.

Known Limitations

Some third-party content, such as listing feeds or embedded tools added in the future, may not fully meet these standards. I'll work with providers to improve accessibility where possible.

Need Help or Have Feedback?

If you have trouble using any part of this site, or need information in another format, please contact me. I'm happy to help by phone or email.
